# AI Travel Itinerary Generator

A simple AI-powered travel planner using HTML, Tailwind CSS, and JavaScript.

## Features
- Generate travel itineraries using AI
- Select destination, days, and budget
- Clean UI with Tailwind CSS
- Uses Groq API with Llama 3.1 model

## Setup
1. Open `script.js`
2. Replace `YOUR_GROQ_API_KEY` with your Groq API key
3. Open `index.html` in a browser
